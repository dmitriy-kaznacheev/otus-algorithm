# Оптимальные деревья поиска: Адаптивное (Splay) и Рандомизированное (Randomized) 

## Цель
Реализовывать оптимальные деревья поиска

## Описание

Реализовать следующие алгоритмы:
### создать адаптивное дерево `splay` 
При каждом обращении (`search`, `insert`, `remove`) целевой узел превращается в корень 
с помощью последовательных поворотов. Это делает дерево эффективным для сценариев с 
"неравномерным" доступом к данным (кэширование).

### создать рандомизированное дерево `rand`
Балансировка достигается вероятностью. При вставке новый узел с вероятностью $1 / (N + 1)$ 
ставится корнем (через повороты), иначе рекурсивно уходит в поддеревья. Это гарантирует 
среднюю высоту $O(log n)$ без хранения приоритетов (в отличие от Treap), но требует хранения
размера поддерева.

Протестировать работу алгоритма:
* создать два дерева
* добавить N чисел в случайном порядке
* искать N/10 случайных чисел в каждом дереве
* удалить N/10 случайных элементов в каждом дереве
