# Шахматные биты

## Цель
Применить битовые маски для определения легальных ходов шахматных фигур

## Описание

**Вход:** число от 0 до 63 (индекс позиции фигуры) <br />
Поля нумеруются: а1 = 0, b1 = 1, ..., h8 = 63.

**Выход:** два числа:
  * количество возможных ходов
  * битовая маска всех возможных ходов короля.

На доске кроме фигуры никого нет.

1. Король (King)
2. Конь (Knight)
3. Ладья (Rook)
4. Слон (Bishop)
5. Ферзь (Queen)
