# Линейные алгоритмы сортировки

## Цель
Реализация, тестирование и сравнение алгоритмов сортировки 

## Описание

Реализовать следующие алгоритмы:
1. `CountingSort` 
2. `RadixSort`
3. `BucketSort`

Произвести тестирование алгоритмов на массиве из сгенерированого бинарного файла, 
который содержит миллиард (N=10^9) целых 16-битных чисел (от 0 до 65535), по 2 байта на каждое число.
