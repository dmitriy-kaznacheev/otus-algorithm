# Префиксное дерево (trie)

## Цель
Реализовать ассоциативный массив (структуру данных для хранения пар «ключ‑значение») 
на основе префиксного дерева, обеспечив выполнение основных операций: 
вставка, поиск и удаление элементов по строковому ключу.

## Описание
1. изучить структуру и принципы работы префиксного дерева;
2. спроектировать класс TrieMap с поддержкой основных операций:
    * вставка пары «ключ‑значение» (`insert`);
    * поиск значения по ключу (`get`);
    * удаление пары по ключу (`remove`);
3. реализовать структуру данных на языке программирования C++.

## Теоретическая часть
**Префиксное дерево (trie)** — структура данных, оптимизированная для хранения и поиска строк. Ключевые особенности:
  1. каждый узел содержит:
      * флаг, указывающий, является ли узел конечным (соответствует полному ключу);
      * значение (если узел конечный);
      * коллекцию дочерних узлов (обычно реализуется через хеш‑таблицу или массив).
  2. ключ не хранится в узле явно — он определяется путём от корня до узла;
  3. корень соответствует пустой строке.

Преимущества для ассоциативного массива:
  1. быстрый поиск, вставка и удаление за O(m), где m — длина ключа;
  2. эффективный поиск всех ключей с общим префиксом (полезен для автодополнения);
  3. упорядоченность ключей (при обходе в глубину).
