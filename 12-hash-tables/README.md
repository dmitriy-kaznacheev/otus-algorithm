# Хэш-таблицы

## Цель
Реализовывать хэш-таблицы с различными способами разрешения коллизий.

## Описание

Реализовать следующие типы хэш-таблиц:
1. методом цепочек (**chaining**) `chain` 
2. метод открытой адресации (**open addressing**) `opena`
  * реализовать "ленивое" удаление
  * реализовать квадратичный пробинг
